# Contributing to Elitea Community

Thank you for helping improve Elitea.

## Before you post

- Search existing issues and discussions first.
- Use the correct channel:
  - Issues for bugs and formal feature requests
  - Discussions for questions, ideas, troubleshooting, and general feedback
- Do not include secrets, tokens, or sensitive data.

## Reporting bugs

Please use the Bug Report template and include:
- a clear summary
- reproduction steps
- expected behavior
- actual behavior
- environment details
- screenshots or logs if available

## Requesting features

Please use the Feature Request template and include:
- the problem to solve
- the proposed solution
- user or business value
- any alternatives considered

## Discussions

Use Discussions for:
- Q&A
- ideas
- troubleshooting
- feedback
- community sharing

## Community standards

By participating, you agree to follow our Code of Conduct.
