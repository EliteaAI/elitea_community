# Support

## Where to get help

- Documentation: https://docs.elitea.ai
- Discussions: [Elitea Community Discussions](https://github.com/EliteaAI/elitea_community/discussions)
- Issues: https://github.com/EliteaAI/elitea_community/issues
- Public project tracking: https://github.com/orgs/EliteaAI/projects/5/views/1

## Use Issues for

- reproducible bugs
- formal feature requests
- actionable documentation issues
- tracked product improvements

## Use Discussions for

- questions
- troubleshooting
- ideas
- general feedback
- broader product conversations

## Before opening a new item

Please:

- search existing issues
- search existing discussions
- avoid duplicates
- use the appropriate template when opening an issue
- redact sensitive information

## Security issues

Do **not** use public issues or discussions for security reports.

See [SECURITY.md](./SECURITY.md) for the correct private reporting process.
