# Support

## Where to get help

- Documentation: `https://docs.elitea.ai`
- Discussions: `[Elitea Community Discussions](https://github.com/EliteaAI/elitea_community/discussions)`
- Bug reports and feature requests: this repository

## Use Issues for

- reproducible bugs
- formal feature requests

## Use Discussions for

- questions
- troubleshooting
- ideas
- general feedback

## Security issues

Do not use public issues or discussions for security reports. See `SECURITY.md`.
