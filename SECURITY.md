# Security Policy

## Reporting a vulnerability

If you believe you have found a **security vulnerability** in Elitea or in this repository, please **do not** report it in public GitHub issues or discussions.

Instead, use **GitHub private vulnerability reporting** for this repository:

1. Go to the **Security** tab of this repository
2. Select **Report a vulnerability**
3. Submit the report privately with as much detail as possible

This is the preferred and official channel for reporting security vulnerabilities for `EliteaAI/elitea_community`.

## What to include

To help the team review your report quickly, please include:

- a clear description of the issue
- the affected feature, component, or workflow
- steps to reproduce
- the potential impact
- proof-of-concept details, if safe to share privately
- any suggested mitigations or fixes, if available

## What not to post publicly

Please do **not** post any of the following in public issues or discussions:

- passwords
- access tokens
- API keys
- customer data
- internal endpoints
- exploit details
- sensitive screenshots or logs
- any information that could put users, systems, or data at risk

## What counts as a security report

Examples may include:

- authentication or authorization bypass
- privilege escalation
- unintended data exposure
- injection vulnerabilities
- sensitive information disclosure
- insecure defaults that create a real security risk
- vulnerabilities in integrations or workflows that could be exploited

## Non-security issues

Please continue to use the public repository for:

- bug reports
- feature requests
- questions
- troubleshooting
- general feedback

Use:

- **Issues** for public bugs and feature requests
- **Discussions** for questions, troubleshooting, and ideas

## Fallback contact

If you are unable to use GitHub private vulnerability reporting, you may contact:

`SupportAlita@epam.com`

Please use email only as a fallback if the GitHub private reporting flow is unavailable.

## Response expectations

The Elitea team will review private vulnerability reports as quickly as possible. Response times may vary depending on severity, complexity, and team availability.

We may request additional information to validate or reproduce the issue.

Thank you for helping keep Elitea and its community safe.
