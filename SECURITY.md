# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public GitHub issues or discussions.

Instead, report them through a private channel:

- Security contact: `SupportAlita@epam.com`

Include:
- a description of the issue
- affected component(s)
- reproduction details
- potential impact
- any proof-of-concept material that is safe to share privately

## What not to post publicly

Do not post:
- access tokens
- passwords
- API keys
- customer data
- internal endpoints
- exploit details

If a vulnerability is posted publicly by mistake, the Elitea team may hide, edit, or remove the content to protect users.
